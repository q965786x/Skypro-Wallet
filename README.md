# Skypro-Wallet

**Skypro-Wallet** — это веб-приложение для контроля личных расходов. Приложение позволяет вести учёт транзакций, анализировать траты по категориям и периодам, а также удобно работать как с десктопа, так и с мобильных устройств.

## Функционал

- **Авторизация и регистрация** — валидация полей, хранение токена в `localStorage`
- **Управление расходами** — добавление, просмотр, удаление транзакций
- **Анализ расходов** — просмотр трат за день / неделю с визуализацией в виде столбчатых диаграмм
- **Адаптивный дизайн** — отдельные компоненты для мобильных устройств (`MainMobile`, `CostCalendarMobile`, `CostDiagramsMobile`)
- **Календарь выбора периода** (мобильная версия) — выбор диапазона дат для анализа
- **Синхронизация с API** — все данные сохраняются на сервере

## Используемые технологии

- **Frontend**: React 18
- **Сборщик**: Vite
- **Маршрутизация**: React Router DOM v6
- **HTTP-клиент**: Axios
- **Стилизация**: Styled Components + CSS (адаптивная верстка)
- **Линтинг**: ESLint
- **Форматирование**: Prettier

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/q965786x/skypro-wallet.git
cd skypro-wallet
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Запуск в режиме разработки

```bash
npm run dev
Приложение будет доступно по адресу: http://localhost:5173
```

### 4. Сборка для production

```bash
npm run build
```

### 5. Предпросмотр собранного приложения

```bash
npm run preview
```

## API

Приложение взаимодействует с бэкендом по адресу:
https://wedev-api.sky.pro/api/

Эндпоинт Метод Описание
/user/login POST Авторизация
/user POST Регистрация
/api/transactions GET Получение всех транзакций
/api/transactions POST Добавление транзакции
/api/transactions/:id PATCH Редактирование транзакции
/api/transactions/:id DELETE Удаление транзакции
/api/transactions/period POST Получение транзакций за период

## Адаптивность

Десктопная версия (width > 768px):

Таблица расходов + форма "Новый расход" на одной странице

Страница анализа: календарь + диаграммы рядом

Мобильная версия (width ≤ 768px):

Отдельные экраны: список расходов → форма добавления

Выбор периода через календарь с возможностью выделения диапазона

Диаграммы с уменьшенными размерами для удобного просмотра

Проект: приложение Skypro-Wallet.
Данное приложение позволяет вести контроль расходов.
Приложение было создано на базе React
Был установлен инструмент Vite, который собрал базовый React-проект.
В проект были установлены библиотеки: react-router-dom - для маршрутизации, axios - для интеграции с API, Prettier и линтер Eslint для форматирования кода.
Приложение состоит из форм авторизации/регистрации, главной страницы "Мои расходы" и страницы "Анализ расходов".
Формы авторизации/регистрации позволяют зарегистрироваться/авторизоваться в приложении, реализована валидация ошибок.
На главной странице "Мои расходы" представлена таблица расходов и форма "Новый расход". В таблице отображаются транзакции, которые были внесены с помощью формы "Новый расход". Есть возможность удаления транзакции.
На странице "Анализ расходов" имеется календарь - для возможности выбрать определенный период совершения транзакций, и форма с диаграммами - для наглядного отображения совершенных транзакций.
Приложение адаптировано под мобильную версию.
